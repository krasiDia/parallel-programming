# LAB 2
## Задание 
  Модифицировать программу из л/р №1 для параллельной работы по технологии OpenMP. Провести экперимент для различного числа потоков и размеров матриц
## Код решения 
### Структура проекта 
```text
ParallelProgramming/
│
├── matrix_1.txt - файл с первой матрицей
├── matrix_2.txt - файл со второй матрицей
├── matrix_result.txt - файл с матрицей-произведением
├── result.txt - файл с результатами замеров времени и объема 
│
├── lab1.cpp - код решения 
├── verify.py - верификация 
│
├── CMakeLists.txt
├── CMakePresets.json
└── README.md
```
  Решение задачи выполнено на языке C++ - **lab1.cpp**. Вычисление произведения двух матриц реализовано с помощью тройного цикла. 
## Эксперимент
  Для удобства я сгенерировала 2 файла: matrix_1 и matrix_2, в которых содержатся матрицы размером 2000*2000. И далее в ходе исследования я меняла только константу SIZE_MATRIX, причем исходные матрицы оставались без изменений. Это позволило мне не создавать дополнительные файлы с матрицами необходимых размеров. 
  
  Для каждого значения SIZE_MATRIX использовался верхний левый квадрат соответствующего размера исходных матриц. Время измерялось с помощью *omp_get_wtime()* только для участка программы, выполняющего умножение матриц.
  
  OpenMP создаёт несколько потоков, которые будут работать над одной задачей. Количество потоков задается через константную переменную NUM_STREAMS. Далее  OpenMP равномерно распределит итерации циклов между всеми потоками еще до их выполнения.
