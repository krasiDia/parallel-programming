# LAB 1
## Задание 
  Написать программу на языке C/C++ для перемножения двух квадратных матриц с обязательной автоматизированной верификацией результатов вычеслений с помощью сторонних библиотек. Сравнить изменения времени выполнения от объема задачи
## Код решения 
### Структура проекта 
```text
ParallelProgramming/
│
├── matrix_1.txt - файл с первой матрицей
├── matrix_2.txt - файл со второй матрицей
├── matrix_result.txt - файл с матрицей-произведением
├── result.txt - файл с результатами замеров времени и объема 
│
├── lab1.cpp - код решения 
├── verify.py - верификация 
│
├── CMakeLists.txt
├── CMakePresets.json
└── README.md
```
  Решение задачи выполнено на языке C++ - **lab1.cpp**. Вычисление произведения двух матриц реализовано с помощью тройного цикла. 
  Верификация реализована на языке Python - **verify.py**. Сравнение проводится с матрицей, полученной в результате применения библиотеки numpy и @.
  
  Для удобства я сгенерировала 2 файла: matrix_1 и matrix_2, в которых содержатся матрицы размером 2000*2000. И далее в ходе исследования я меняла константу SIZE_MATRIX без создания дополнительных файлов с матрицами разных размеров или генерацией таких матриц
